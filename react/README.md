# 🔄 Drag & Drop

A clean, responsive, and smooth Drag & Drop list interface built with **React** and **Tailwind CSS**. 

This project demonstrates how to handle complex state updates and cross-list dragging seamlessly using the `react-sortablejs` library.

---

### ✨ Features

- **Cross-List Dragging:** Items can be dragged and dropped between multiple lists using a shared group configuration.
- **Empty List Recovery:** Implemented `emptyInsertThreshold` to ensure items can always be dropped back into an empty list, preventing UI lockups.
- **Smooth Animations:** Native Sortable.js animations provide a premium, fluid user experience.
- **Custom Tailwind UI:** Features a modern design with dashed borders, hover effects, and dynamic cursor states (`cursor-grab` to `cursor-grabbing`).

---

### 🛠️ Tech Stack

- ⚛️ **React** (Functional Components & `useState`)
- 🔄 **react-sortablejs** (Powered by Sortable.js for robust drag-and-drop)
- 🎨 **Tailwind CSS** (Utility-first styling)
